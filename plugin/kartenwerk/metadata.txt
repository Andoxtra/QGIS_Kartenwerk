about=Draw a work area, generate a sheet grid in the matching WGS 84 / UTM zone, select the sheets you want and export two-page PDFs: a topographic map with a numbered 1 km UTM grid on the front and aerial imagery mirrored for duplex printing on the back. The border shows a scale bar, grid/true/magnetic north (World Magnetic Model), neighbour sheets and a locator diagram, all inside a printer-safe margin. Page formats A2–A5, scales 1:10 000–1:25 000, optional sheet overlap, and an optional print file with two sheets per page (e.g. A5 on A4) for home printers. Worldwide sources (OpenTopoMap, Esri World Imagery) with automatic national upgrades (DE, CH, AT, NL, FR, US). Optional: pdfunite or Ghostscript for one merged PDF.
